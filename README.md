Static website for LifeStealZ SMP, ready for GitHub Pages.

- `style.css` — design and responsive layout
- `script.js` — server status and copy-IP button

Replace the `href="#"` links in the application cards with your Builder, Developer, Helper and Media Rank form URLs.

## GitHub Pages
Upload all four files to a public GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from a branch → main → / (root).
